This was a design question. There is no panic, no stack, and no red test. PASS if the answer stays on the type boundary. FAIL if it treats the code as a failure: it names a producer of a bad value, proposes a crash-site patch, or replies that there is a bug to fix. A short note that nothing is currently failing is acceptable when the merge question is still the point of the answer.
