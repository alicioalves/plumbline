Plumbline

Agent skills that check code against A Philosophy of Software Design. Like a builder's plumb line, each skill gives your agent a simple, concrete test for whether the design is still standing straight, during implementation and review.

v{{VERSION}} · GitHub · Releases · All install options

Install in Claude Code

/plugin marketplace add tomymaritano/plumbline
/plugin install plumbline@plumbline-plugins

Also for Codex, Cursor, Grok Build, OpenCode, Copilot CLI, Kimi, Pi and any Agent Skills host via npx skills add tomymaritano/plumbline --skill '*'.
